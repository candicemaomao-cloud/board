# 导数高级策略：逐笔与消融诊断

2026-09-29。此轮只研究，不修改策略或用户参数。

## 方法与限制

币安公开BTCUSDT及ETHUSDT合约30分钟数据，每个标的取得10176根。
分别检查4—6月、7—8月、9月8—28日；6种固定规则：V2、移除ADX、移除追价限制、
量比门槛降至0.1、移除回踩、移除延后跟踪门槛。总共36组，不做参数搜索。
每组本金10000、固定名义本金、复利、单边手续费5bp、滑点2bp，跟踪距离3ATR。
风险定仓关闭，隔离“减仓”与“信号质量”变化。量比0.1并不是完全禁用量能。
移除追价条件也同时移除了下一根开盘跳价取消，因此该项不是纯粹的单因素检验。

脚本以截止日23:59:59作上界，仅纳入已收盘K线，因此未纳入截止日最后一根23:30开盘K线。
这些是诊断区间而非独立样本外验证。未计资金费，也未以多个变体中最好结果作为新默认。

## 代码机制与研究假设

- EMA触碰定义过宽：只有影线穿过EMA也能算回踩，没有确认此前存在趋势推动和有效回撤。
- 恢复条件仅为突破上一根K线高低点，不一定越过整个回踩段的结构。
- 方向要求高周期快EMA当下仍在上升/下降；回踩中变平会将方向设0并取消等待中的回踩。
  因此“允许回踩”与“短时趋势仍持续加速”的条件可能冲突，需要单独研究，而非继续加指标。
- 跟踪止损按距离收紧，但没有区分“结构失效退出”和“盈利后的保护”；不能靠增大止损
  或缩小止盈机械提高胜率。

后续候选应首先定义完整的推动—回撤—恢复结构，用结构位决定失效点，并独立比较
结构跟踪与扣费后保本机制。先固定规则，再跨区间、跨币种测试，不能凭上述四笔反向
设计“必然赚钱”的条件。
